Dhaka Crime Map — Pipeline Report

26 October 2026 · in-house deployment on genweb2inhouse (192.168.1.200) · repository github.com/zawadgenweb2/dhaka-crime-map · status: live

1. What it does

  • Collects crime news from Prothom Alo (Bangla) twice a day (08:00 and 20:00 Asia/Dhaka), plus on-demand backfills of past days.
  • An in-house language model (Gemma 4 E2B) reads each likely crime article and extracts incidents: crime type, place in Dhaka district, date, time of day, victims and a verbatim supporting quote.
  • Incidents that pass automatic checks appear on a bilingual (Bangla/English) live heat map with filters, hotspots and a news feed; every point links to its source article. No external AI service is used.

6. Safeguards

  • Only in-house Gemma output is served; every endpoint checks provenance.
  • Evidence: each incident carries a quote that must appear word for word in the article.
  • Location grounding: the place must be named where the crime is described; another district in the lead blocks it.
  • Reliability: every model call is recorded before it is sent and every answer saved, so re-checking needs no new model calls; an older job can never overwrite newer output.
  • Coverage honesty: each day is marked complete, processing, partial, failed or not collected; the map warns when a period is incomplete.
  • Politeness: robots.txt, 1 request/s to the publisher, OpenStreetMap ≤ 4/min.
  • Security: LAN-only HTTPS; admin token for actions that change data or use the GPU; secrets never in git.
  • Backups: nightly database dump, 14 days kept.

8. Known limits

  • One newspaper; these are reported incidents, not all crime. Results are published without human review, so some errors reach the map (incident precision ≈ 0.8).
  • The model still sometimes splits one event into several incidents (e.g. extortion + kidnapping + assault for one case); dates are the weakest field.
  • Older days: Prothom Alo's daily lists have no titles, so past sports/business/world articles are not examined (a 48-hour audit found no Dhaka crime among them).
  • Points without a named street sit at the neighbourhood or thana centre. Browser shows "Not secure" (self-signed LAN certificate) until Tailscale HTTPS is enabled.
